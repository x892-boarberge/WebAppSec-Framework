# WebAppSec Framework

This package contains the deliverables extracted from the supplied project text.

## Run the prototype

From this project folder, run:

```bash
python -m http.server 8000
```

Then open:

`http://localhost:8000/prototype/index.html`

The JSON register is loaded by the prototype using `fetch()`, so it must be served over HTTP rather than opened directly using `file://`.
